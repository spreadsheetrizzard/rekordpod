# Rekordpod public-beta release gate

The canonical and maintained release gate is now [../../TESTING.md](../../TESTING.md).
It includes automated checks, target and storage matrices, write-path parity,
stop-ship criteria, and the screenshot-harvesting checklist.

Do not use an older copied checklist to approve a new archive. Record plugin
memory use and archive hashes from the exact release commit in its release
manifest.
